# 🧮 Simple Calculator

A basic arithmetic web application built with **Python** and **Streamlit**.

## Features

- **Addition (`+`)**: Calculates the sum of any number of comma-separated numeric values.
- **Subtraction (`-`)**: Takes two numbers and displays both `first - second` and `second - first`[cite: 1].
- **Multiplication (`*`)**: Multiplies a comma-separated list of numeric values together[cite: 1].
- **Division (`/`)**: Divides the first number by the second, with a guard against division by zero[cite: 1].

## Prerequisites

- Python 3.x
- Streamlit (`pip install streamlit`)

## Installation & Running

1. Save the calculator script as `main.py`[cite: 1].
